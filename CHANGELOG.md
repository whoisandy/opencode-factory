# opencode-factory

## 0.1.0

### Added

- OpenCode V2 agent pack: `foreman`, `machinist`, `sage`, `explorer`, `librarian`, `reviewer`, `advisor`, and `curator`.
- Argument-based commands: `/factory`, `/ultrawork`, `/improve`, `/plan`, `/review`, `/context`, `/sage`, and `/commit`.
- Skills `improve` and `context` with their reference material.
- Read-only project-context plugin (`factory_context`) with opt-in `contextNudge` and runtime-only `builtinAwareness`.
- `ocf` installer CLI (`install`, `update`, `uninstall`, `doctor`) with preview output, manifest tracking, and backups.
